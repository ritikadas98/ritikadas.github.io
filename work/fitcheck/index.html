FitCheck

A calculator, not a guess. It reads the size chart already on the page and works out whether the size will actually fit.

Add to Chrome ↗ Try it live, no install ↗ Source ↗

Chrome, Edge, Brave or any Chromium browser. The side panel it runs in does not exist in Firefox or Safari.

ProblemA quarter to a third of clothing orders in India come back, and size is the biggest reason. Each return costs shipping both ways, handling, and often a garment that can’t be resold. The chart that would prevent it is already on the page, unread.
DecisionA calculator, not a guess. It compares the fit a garment was designed for with the fit you’d actually get. The chart is already exact, so arithmetic is the right tool.
EvidenceTen installs. 70% were still using it a week later. Nobody uninstalled it. And it refuses to answer when the size chart is missing or unreadable — six times in twenty-one, where it says so instead of guessing.
OutcomeIt caught a sizing mistake of mine that had already cost a return and an exchange. Every verdict can be checked against the store’s own chart.

The Label Said 30. So Did My Waist.

I ordered Levi’s jeans in size 30. My waist is 30 inches. They arrived too loose, and I exchanged them for a 28.

Then I read the size chart on the page I had just bought from. On that cut, a 28 is made for a 30-inch waist. The label was never a measurement. It was a name — and it had been sitting two scrolls down the whole time I was ordering the wrong thing.

That week I had Myntra, AJIO, H&M and Westside open at once. The same letter meant four different bodies. Every page already had its chart. So the chart was never the problem. Trusting it was.
